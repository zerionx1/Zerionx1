# Zerion X1 ZIP 3 — Strategy Research Workspace

Includes:
- Private strategy workspace tabs
- Zerion-curated multi-market strategy marketplace
- Install-and-customize templates
- Persistent historical backtesting interface
- Saved backtest history
- Equity curve, metrics and trade inspection
- Parameter candidate planning with invalid-combination rejection
- Supabase indexes for strategy and backtest retrieval

Real historical performance requires an operational market-data provider. The UI returns an explicit provider error rather than fabricated performance.
