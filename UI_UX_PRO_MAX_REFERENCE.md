# UI/UX reference used for Phase 14–15

The attached video shows the `nextlevelbuilder/ui-ux-pro-max-skill` project.

The Phase 14–15 UI layer uses the useful ideas rather than copying the repository wholesale:
- Glassmorphism only where hierarchy benefits from it.
- AI-native workspace pattern for the Zerion copilot.
- Bento-like grouped information instead of endless identical cards.
- Four-colour surface system from Zerion Phase 13.
- Clear primary and secondary actions.
- Simple English and lower cognitive load.
- Visible status, empty-state and error-state design.
- Mobile-first responsive layouts.
- Reduced-motion support for accessibility.
- Financial dashboard patterns with separate account-state and execution-state surfaces.
- No decorative animation on critical confirmation controls.

The UI/UX Pro Max repository is a design intelligence skill/database, not a component library. It provides style, palette, typography, chart, UX, React and stack guidance. Phase 14–15 applies those ideas directly to Zerion's existing Next.js/Tailwind/CSS architecture.
