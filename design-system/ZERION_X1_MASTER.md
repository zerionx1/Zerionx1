# Zerion X1 — UI/UX Pro Max Applied Design System

Source reference: nextlevelbuilder/ui-ux-pro-max-skill

Applied patterns:
- Financial Dashboard
- AI-Native UI
- Liquid Glass (controlled)
- Bento Grid
- Dimensional Layering
- Micro-interactions
- Responsive 375/768/1024/1440
- Visible focus states
- Reduced-motion support
- Lucide icons only

Four-color surface system:
1. Graphite #0B0F14 — 52%
2. Oxblood #3A2028 — 8%
3. Antique Bronze #B78A56 — 14%
4. Cool Slate #697586 — 26%

Warm ivory #EEE6D8 is text, not a surface color.

Rules:
- Never flood a page with maroon/oxblood.
- Cards use graphite/slate glass layers.
- Bronze is CTA/status/accent only.
- Oxblood is a very small atmospheric accent.
- Important information must be readable without decorative effects.
- Mobile layouts must not rely on horizontal overflow for core actions.
