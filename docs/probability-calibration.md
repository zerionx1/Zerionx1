# Probability Calibration

## Scope
This module is deterministic, typed, auditable and provider-neutral. It does not promise profit or accuracy. Production activation requires licensed data, model evaluation, calibration, drift monitoring, independent approval, user disclosures and operational monitoring.

## Release gates
- Fresh and licensed data
- Versioned model or deterministic rule
- Explainable factors
- Calibration evidence
- No guaranteed-return language
- Audit trail and rollback
- Load, security and failure-mode tests
