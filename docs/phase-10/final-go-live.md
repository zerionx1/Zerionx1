# Final Go-Live Checklist

This control is mandatory before production activation. Configuration must use approved providers, encrypted secrets, least privilege, audit logging, rollback instructions, monitored health checks, and a tested failure path. No live-money feature may be enabled until its sandbox, reconciliation, duplicate prevention, consent, and kill-switch tests pass.

## Release evidence

- Owner and approver recorded
- Environment configuration validated
- Automated tests passed
- Monitoring and alerts verified
- Recovery procedure exercised
- Audit evidence retained
